# Support

## Bugs and feature requests

Use the repository's structured GitHub issue forms. Include a minimal
reproduction, the Anhedral version, the command you ran, the selected modules,
and the relevant non-secret output.

Search existing issues before opening a new one. Keep each issue focused on one
actionable problem or proposal.

## Security vulnerabilities

Do not report suspected vulnerabilities in a public issue. Follow
[`SECURITY.md`](SECURITY.md) and use GitHub private vulnerability reporting.

## Generated application support

Anhedral maintains the generator and its generated integration contracts. For
questions about an upstream framework or provider that are not caused by
generated configuration, use that project's official support channel.

Never post credentials, private application data, production logs containing
personal data, or complete environment files.
